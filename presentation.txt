  SECTION 1: PROJECT OVERVIEW
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Sugam Seva is a mobile-first citizen services platform built for Indian
citizens to manage government documents and discover eligible government
schemes. The application combines document management, AI-powered scheme
recommendation, and an intelligent chatbot — all in one unified platform.

  → Name       : Sugam Seva (सुगम सेवा / ಸುಗಮ ಸೇವಾ)
  → Tagline    : "Citizen Services, Simplified"
  → Status     : Prototype (functional MVP)
  → License    : MIT
  → Languages  : English, Hindi, Kannada (trilingual UI + chatbot)

  SECTION 7: KEY FEATURES IN DETAIL
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  7.1  DOCUMENT MANAGEMENT
  ─────────────────────────
  • Upload via: Gallery/File Picker, Camera Capture, DigiLocker (UI stub)
  • Supported types: Aadhaar, PAN, Passport, Driving Licence, Voter ID,
    Income Certificate, Education Certificate, Birth Certificate,
    Disability Certificate (UDID), Ration Card, EWS Certificate
  • Client-side OCR using Tesseract.js (runs entirely in the browser)
  • Automatic extraction of name, DOB, address, ID numbers
  • 4-digit PIN protection for documents
  • Blurred thumbnails for privacy in the dashboard grid
  • "Where can I get it?" helper — shows official govt. website per document

  7.2  GOVERNMENT SCHEME DISCOVERY
  ──────────────────────────────────
  • 10 pre-imported verified schemes from approved-schemes.json
  • Eligibility engine evaluates: age, income, state, document holdings
  • Each scheme shows: benefits, eligibility, required docs, deadlines
  • Ranked recommendations based on user profile completeness
  • Filter by scope (central/state) and by state

  7.3  AI CHAT ASSISTANT
  ───────────────────────
  • Floating FAB button accessible from every page
  • Powered by Groq API with Qwen 3.6-27B (with automatic fallback)
  • Strict system prompt — ONLY answers scheme-related questions
  • Polite refusal for off-topic queries
  • Quick-reply suggestion chips (4 common questions)
  • Supports English, Hindi, and Kannada responses
  • Conversation history (last 8 messages) for context
  • Thinking tag stripping for clean responses

  7.4  USER EXPERIENCE
  ─────────────────────
  • Indian tricolour accent bar (saffron-white-green) at the top
  • Emerald green design theme with CSS custom properties
  • Responsive mobile-first layout (adaptive grid)
  • Biometric/passkey setup prompt (WebAuthn-ready prototype)
  • Profile auto-populated from OCR-extracted data
  • National anthem player (Jana Gana Mana) in the footer
  • Skip link for accessibility
  • prefers-reduced-motion respected

  SECTION 8: SECURITY & VALIDATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  • Helmet.js for HTTP security headers
  • Parameterised SQL queries (no raw string interpolation)
  • Input validation on all API endpoints (regex, length, type checks)
  • Official URLs must be HTTPS and belong to *.gov.in domains
  • GROQ_API_KEY stays server-side only (never sent to browser)
  • CORS protection with configurable origins
  • JSON body size limited to 32 KB

  SECTION 10: SCHEME IMPORT PIPELINE

  npm run import:schemes -- ./approved-schemes.json

  Pipeline Steps:
  1. Read and parse JSON file (array or { schemes: [...] })
  2. Validate each record (required fields, HTTPS govt. URLs only)
  3. Upsert into schemes table (ON CONFLICT on id)
  4. Delete & re-insert scheme_documents (fresh document list)
  5. Upsert into scheme_eligibility_rules (JSONB rules)
  6. Entire import wrapped in a transaction (BEGIN/COMMIT/ROLLBACK)
